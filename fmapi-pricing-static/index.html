Integrity checks

    Reading these numbers

    • Cost = ordinary input × input rate + cache-read input × read rate + cache-write input × write rate + output × output rate, each token count divided by 1,000,000.
    • Caching shares describe how tokens are billed. They do not configure an endpoint or guarantee cache support. Measure cached tokens ÷ total input tokens before budgeting savings.
    • With Claude, a positive read share and zero writes is a warmed-cache period, not a full lifecycle budget. Writes can make savings negative.
    • "Not priced" means a cache-write price this scenario needs is not listed in the rate snapshot. It is never treated as free.
    • Excludes app compute, storage, network, taxes, tool and search fees, and commercial margin. Output assumptions should cover all billable output, including reasoning tokens where charged.
